<Note>
This is a special-model parameter guide for the [Text to Image / Image to Image API](/ai-tools-suite/image-generate/create-by-source-prompt). Material IDs are scoped to the parameter whose table lists them; do not reuse an ID with a different parameter.
</Note>

## Quick start

Use this page in the following order:

1. Send the request to the [Text to Image / Image to Image API](/ai-tools-suite/image-generate/create-by-source-prompt) with `model_name` set to `meitu/yunxiu-pro/image-to-image`.
2. Copy the five `people_type` entries exactly as shown below. Their content and order are fixed.
3. Add only the effects you need under `parameter.all_params`.
4. For a complex effect such as makeup, filters, hair color, or sky replacement, follow the link in the complete parameter table to select a valid material ID.

### Minimal complete request

This example applies global exposure to the image and removes under-eye bags for all five audience groups.

```json
{
  "model_name": "meitu/yunxiu-pro/image-to-image",
  "source_images": ["https://example.com/source.jpg"],
  "parameter": {
    "people_type": [
      { "age": [15, 49], "gender": 1, "key": "man", "name": "" },
      { "age": [15, 49], "gender": 0, "key": "woman", "name": "" },
      { "age": [0, 14], "gender": 0, "key": "child", "name": "" },
      { "age": [50, 100], "gender": 0, "key": "oldwoman", "name": "" },
      { "age": [50, 100], "gender": 1, "key": "oldman", "name": "" }
    ],
    "all_params": {
      "exposure": 20,
      "remove_pouch": [30, 30, 30, 30, 30]
    }
  },
  "batch_quantity": 1,
  "webhookurl": "https://example.com/webhook"
}
```

## How to choose the correct value shape

The `Type` column in the complete table determines how a value must be sent.

| Table type | When to use it | Example |
| --- | --- | --- |
| `int` | One value applies to the whole image | `"exposure": 20` |
| `bool` | Enables or disables a global option | `"color_grading_global_enable": true` |
| Standard `list` | One intensity per audience group | `"remove_pouch": [30, 20, 0, 10, 10]` |
| Makeup `list` | One material item per audience group | `"eyebrow": [{ "id": "biaozhunmei", "color": "0;0;0;255", "alpha": 50 }, ...]` |
| `dict` | A nested, effect-specific object | `"filter": { "filter_id": "Fa0000qhjvzrB6bk", "filters_lut_alpha": 50 }` |
| Curve `list` | Flattened x/y curve coordinates | `"gray_point": [0, 0, 128, 140, 255, 255]` |

<Warning>
A standard five-item list and a makeup five-item list are different structures. Standard lists contain integers. Makeup lists contain objects with `id`, `color`, and `alpha`.
</Warning>

## Common examples

### Apply different intensities by audience group

The fixed list order is:

| Index | `people_type.key` | Audience |
| --- | --- | --- |
| 0 | `man` | Adult man |
| 1 | `woman` | Adult woman |
| 2 | `child` | Child |
| 3 | `oldwoman` | Older woman |
| 4 | `oldman` | Older man |

For example, this applies stronger under-eye-bag removal to adult women and no effect to children:

```json
{
  "all_params": {
    "remove_pouch": [20, 60, 0, 30, 30]
  }
}
```

### Apply an eyebrow material

Select `id` from the [eyebrow material enum](#makeup-eyebrow). Every makeup parameter requires exactly five items.

```json
{
  "all_params": {
    "eyebrow": [
      { "id": "biaozhunmei", "color": "0;0;0;255", "alpha": 30 },
      { "id": "biaozhunmei", "color": "108;66;24;255", "alpha": 50 },
      { "id": "biaozhunmei", "color": "0;0;0;255", "alpha": 0 },
      { "id": "biaozhunmei", "color": "137;100;41;255", "alpha": 30 },
      { "id": "biaozhunmei", "color": "0;0;0;255", "alpha": 30 }
    ]
  }
}
```

The selected material ID belongs only to `eyebrow`. Do not use it for `eye`, `eyeshadow`, or another makeup parameter.

### Apply a filter

Select `filter_id` from the [filter material enum](#filter-parameter-structure). The intensity range is 0–100.

```json
{
  "all_params": {
    "filter": {
      "filter_id": "Fa0000qhjvzrB6bk",
      "filters_lut_alpha": 50
    }
  }
}
```

### Replace the sky

Select `logic_id` from the [sky material enum](#sky-background-structure).

```json
{
  "all_params": {
    "sky_background": {
      "logic_id": "2130",
      "params": {
        "sky_wap_flag": 1,
        "sky_shift_x_coef": 0,
        "sky_shift_y_coef": 0,
        "sky_blip_flag": 0,
        "sky_edge_dilate_coef": 0,
        "sky_edge_blur_coef": -10,
        "blur_coef": 0,
        "sky_alpha_coef": 100,
        "sky_exposure": 0,
        "sky_saturability": 0,
        "sky_scale_coef": 0,
        "sky_temperature": 0
      }
    }
  }
}
```

### Combine multiple effects

Multiple independent parameters can be placed in the same `all_params` object:

```json
{
  "all_params": {
    "exposure": 15,
    "saturability": 10,
    "remove_pouch": [20, 40, 0, 20, 20],
    "bright_eye": [20, 30, 0, 20, 20],
    "filter": {
      "filter_id": "Fa0000qhjvzrB6bk",
      "filters_lut_alpha": 30
    }
  }
}
```

Only include parameters you intend to change. Use the complete table below to confirm the type and accepted range before sending a value.

## Common validation mistakes

### Incorrect audience-list length

Standard list parameters require exactly five values.

| Invalid | Correct |
| --- | --- |
| `"remove_pouch": [30, 30, 30]` | `"remove_pouch": [30, 30, 30, 30, 30]` |

### Incorrect makeup value shape

Makeup parameters require five item objects, not five integers.

```json
{
  "eyebrow": [30, 30, 30, 30, 30]
}
```

Use the shared makeup structure instead:

```json
{
  "eyebrow": [
    { "id": "biaozhunmei", "color": "0;0;0;255", "alpha": 30 },
    { "id": "biaozhunmei", "color": "0;0;0;255", "alpha": 30 },
    { "id": "biaozhunmei", "color": "0;0;0;255", "alpha": 30 },
    { "id": "biaozhunmei", "color": "0;0;0;255", "alpha": 30 },
    { "id": "biaozhunmei", "color": "0;0;0;255", "alpha": 30 }
  ]
}
```

### Material ID used with the wrong parameter

Each material table is parameter-specific. For example, an ID from the [eyebrow table](#makeup-eyebrow) is valid only in `eyebrow[].id`; it cannot be used in `eye[].id` or `eyeshadow[].id`.

### Value outside its documented range

The following value is invalid because `filters_lut_alpha` accepts 0–100:

```json
{
  "filter": {
    "filter_id": "Fa0000qhjvzrB6bk",
    "filters_lut_alpha": 120
  }
}
```

### Unsupported source image

Only JPG, JPEG, and PNG are supported. Images larger than 15000 × 15000 cannot be submitted. Endpoint selection for smaller images is automatic; clients must not send an endpoint-selection parameter.

## 1. Parameter object structure

`parameter` uses the following top-level structure:

```json
{
  "people_type": [
    { "age": [15, 49], "gender": 1, "key": "man", "name": "" },
    { "age": [15, 49], "gender": 0, "key": "woman", "name": "" },
    { "age": [0, 14], "gender": 0, "key": "child", "name": "" },
    { "age": [50, 100], "gender": 0, "key": "oldwoman", "name": "" },
    { "age": [50, 100], "gender": 1, "key": "oldman", "name": "" }
  ],
  "all_params": {}
}
```

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `people_type` | Object array | Yes | Exactly five audience entries in the documented order; do not modify the content or order |
| `all_params` | Object | Yes | Collection of retouching parameters |

## 2. Value-shape rules

| Type | Value shape | Rule |
| --- | --- | --- |
| `int` | One integer | Use the range or enum in the complete parameter table |
| `bool` | `true` / `false` | Boolean values only |
| Standard `list` | Five integers | Order: man, woman, child, oldwoman, oldman |
| Makeup `list` | Five makeup item objects | Each item contains `id`, `color`, and `alpha` |
| `dict` | Object | Use the parameter-specific structure linked from the table |
| Curve `list` | Flattened curve points | Coordinate values are 0–255; this is not a five-audience intensity list |

Example standard list:

```json
{ "remove_pouch": [30, 30, 30, 30, 30] }
```

## 5. Shared makeup item structure

The following parameters use a fixed five-item array in `people_type` order: `mouth`, `facialdecals`, `feature`, `blush`, `eye`, `eyebrow`, `eyelash`, `eyeshadow`, and `eyesocket`.

```json
{
  "eyebrow": [
    { "id": "biaozhunmei", "color": "0;0;0;255", "alpha": 50 },
    { "id": "biaozhunmei", "color": "0;0;0;255", "alpha": 50 },
    { "id": "biaozhunmei", "color": "0;0;0;255", "alpha": 50 },
    { "id": "biaozhunmei", "color": "0;0;0;255", "alpha": 50 },
    { "id": "biaozhunmei", "color": "0;0;0;255", "alpha": 50 }
  ]
}
```

| Item field | Type | Description |
| --- | --- | --- |
| `id` | String | An ID from the material table for this parameter |
| `color` | String | A supported color code or RGBA value where the material table provides one |
| `alpha` | Integer | Intensity from 0 to 100 |

## 13. Source image constraints

| Source image condition | Provider endpoint | Formats |
| --- | --- | --- |
| Width and height are both no more than 1500px | `/openapi/preview_chain.json` | JPG, JPEG, PNG |
| Either side is greater than 1500px and both sides are no more than 15000px | `/openapi/chain.json` | JPG, JPEG, PNG |

The openapi-job service reads the image header and selects the provider endpoint automatically. If either side exceeds 15000px, the format is unsupported, or metadata cannot be parsed, task creation fails before the provider create endpoint is called.

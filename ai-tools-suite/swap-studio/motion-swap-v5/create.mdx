---
title: "Create Task"
description: "Create Task for Motion Swap V5."
openapi: "POST /api/open/v5/motionSwap/create"
---

```
POST https://openapi.akool.com/api/open/v5/motionSwap/create
```

**Request Headers**

| **Parameter** | **Value** | **Description** |
|---|---|---|
| x-api-key | API Key | API key used for authorization. Authorization takes precedence when both headers are supplied. |
| Authorization | Bearer `{token}` | [Get Token](/authentication/usage#get-the-token). |
| Content-Type | application/json | Required for JSON requests. |

<Note>
Each reference image produces a separate video task. Use a model returned by this operation's models endpoint and its exact resolution values. Optional mode is forwarded for Wan; character_orientation is used for Kling. duration does not trim or replace the measured driving-video duration.
</Note>

**Body Attributes**

| **Parameter** | **Type** | **Required** | **Description** |
|---|---|---|---|
| video | String | true | Public driving video URL. |
| images | Array | true | 1–50 public character image URLs. Each image creates an independent video task. |
| model_name | String | true | Motion-control model ID from the models endpoint. |
| resolution | String | false | Case-sensitive resolution supported by the selected model. |
| mode | String | false | Wan models: `animate` or `replace`, defaults to `animate`. |
| prompt | String | false | Optional instructions: up to 2500 characters for Kling and 5000 for Wan. Overlong prompts are rejected before generation. |
| negative_prompt | String | false | Optional negative instructions, up to 5000 characters, for Wan/Kling models. |
| character_orientation | String | false | Kling models: `image` or `video`, defaults to `video`; image orientation supports at most 10 seconds. |
| keep_original_sound | Boolean | false | Keep source audio in the generated video; defaults to true. |
| duration | Number | false | Optional compatibility field (1–120). The server measures the actual video duration for limits and billing; this field does not trim or override it. |
| webhookUrl | String | false | Optional final-state callback URL; follow the [Webhook guide](/ai-tools-suite/webhook). |

**Response Attributes**

| **Parameter** | **Type** | **Description** |
|---|---|---|
| code | Integer | Business response code; `1000` means the request succeeded. |
| msg | String | Response message. |
| data | Object | Batch creation result. |
| - list | Array | Successfully created tasks. |
| -- _id | String | Task ID to use for result polling. |
| -- task_id | String | Downstream algorithm/provider task ID; may be empty until submission. Use `_id`, not this value, for task-detail queries. It may change between workflow stages. |
| -- status | Integer | Initial task status. |
| -- media_type | String | Output media type: image or video. |
| -- model_name | String | Selected model ID. |
| -- deduction_credit | Number | Task billing amount. |
| -- create_time | Number | Creation timestamp in milliseconds. |
| - errors | Array | Inputs that could not create a task. Inspect this array even when code is 1000. |
| -- index | Integer | Zero-based plan/input index that failed during submission. |
| -- error | String | Submission failure description. |

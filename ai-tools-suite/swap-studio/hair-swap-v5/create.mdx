title: "Create Task"

openapi: "POST /api/open/v5/hairswap/create"
---

```
POST https://openapi.akool.com/api/open/v5/hairswap/create
```

**Request Headers**

| **Parameter** | **Value** | **Description** |
|---|---|---|
| x-api-key | API Key | API key used for authorization. Authorization takes precedence when both headers are supplied. |
| Authorization | Bearer `{token}` | [Get Token](/authentication/usage#get-the-token). |
| Content-Type | application/json | Required for JSON requests. |

<Note>
Use images for reference-image batches or mappings for per-face selection. When mappings is supplied it takes precedence; top-level face indexes apply only to the images shortcut. Multi-person targets combine mappings into one primary task and each target face can appear only once. multi_shot=true requires a single-person target and at most 12 references (four outputs per primary task).
</Note>

**Body Attributes**

| **Parameter** | **Type** | **Required** | **Description** |
|---|---|---|---|
| target_url | String | true | Public target portrait image URL. |
| images | Array | conditional | 1–50 reference hairstyle image URLs (at most 12 with `multi_shot: true`). Provide `images` or `mappings`. |
| mappings | Array | conditional | 1–50 objects (at most 12 with `multi_shot: true`); takes precedence over `images`. |
| mappings[].source_url | String | true | Reference hairstyle image URL. |
| mappings[].target_face_index | Integer | false | Zero-based target face index for this mapping; defaults to 0. |
| mappings[].source_face_index | Integer | false | Zero-based reference face index for this mapping; defaults to 0. |
| multi_shot | Boolean | false | Generate three additional hairstyle views; defaults to false. Single-person targets only. |
| target_face_index | Integer | false | Zero-based target face index for `images` only; defaults to `0`. For `mappings`, set it on each mapping. |
| source_face_index | Integer | false | Zero-based reference face index for `images` only; defaults to `0`. For `mappings`, set it on each mapping. |
| model_name | String | false | Defaults to `akool/hair-swap`. |
| webhookUrl | String | false | Optional final-state callback URL; follow the [Webhook guide](/ai-tools-suite/webhook). |

**Response Attributes**

| **Parameter** | **Type** | **Description** |
|---|---|---|
| code | Integer | Business response code; `1000` means the request succeeded. |
| msg | String | Response message. |
| data | Object | Batch creation result. |
| - list | Array | Successfully created tasks. |
| -- _id | String | Task ID to use for result polling. |
| -- task_id | String | Downstream algorithm/provider task ID; may be empty until submission. Use `_id`, not this value, for task-detail queries. It may change between workflow stages. |
| -- status | Integer | Initial task status. |
| -- media_type | String | Output media type: image or video. |
| -- model_name | String | Selected model ID. |
| -- deduction_credit | Number | Task billing amount. |
| -- create_time | Number | Creation timestamp in milliseconds. |
| - errors | Array | Inputs that could not create a task. Inspect this array even when code is 1000. |
| -- index | Integer | Zero-based plan/input index that failed during submission. |
| -- error | String | Submission failure description. |

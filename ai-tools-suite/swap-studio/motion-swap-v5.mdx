Transfer movement from one driving video to up to 50 character images.

The video supplies movement; the images supply character appearance. This endpoint does not perform the character replacement workflow. Each image has its own task ID and result.

## Supported models

```
GET https://openapi.akool.com/api/open/v5/motionSwap/models
```

Use your API key to list models available for this operation. The response is `data.list`. Each item includes `model_name`, `label`, `description`, `icon`, `provider`, `params`, `unit_price_map`, and `requires_priority`. Use `params` for supported resolutions, defaults, and input limits; `unit_price_map` is the configured pricing map. Your final charge also depends on account/team pricing. Model availability can change; do not use a model ID from another operation.

```bash cURL
curl --location 'https://openapi.akool.com/api/open/v5/motionSwap/models' \
--header 'x-api-key: {{API Key}}'
```

### Model IDs

| Model ID | Configured resolutions |
|---|---|
| `pixverse/motion-control` | `360p`, `540p`, `720p` |
| `kwaivgi/kling-v3.0-pro/motion-control` | `720P`, `1080P` |
| `kwaivgi/kling-v3.0-std/motion-control` | `720P`, `1080P` |
| `kwaivgi/kling-v2.6-pro/motion-control` | `720P`, `1080P` |
| `kwaivgi/kling-v2.6-std/motion-control` | `720P`, `1080P` |
| `wavespeed-ai/wan-2.2/animate` | `360p`, `480p`, `540p`, `720p` |

Use the models endpoint for current availability. Head Swap and Akool Character Swap creation accept only `480p` or `720p`, even if a shared configuration advertises other resolutions.

## Create task

```
POST https://openapi.akool.com/api/open/v5/motionSwap/create
```

**Request Headers**

| **Parameter** | **Value** | **Description** |
|---|---|---|
| x-api-key | API Key | API key used for authorization. Authorization takes precedence when both headers are supplied. |
| Authorization | Bearer `{token}` | [Get Token](/authentication/usage#get-the-token). |
| Content-Type | application/json | Required for JSON requests. |

**Body Attributes**

| **Parameter** | **Type** | **Required** | **Description** |
|---|---|---|---|
| video | String | true | Public driving video URL. |
| images | Array | true | 1–50 public character image URLs. Each image creates an independent video task. |
| model_name | String | true | Motion-control model ID from the models endpoint. |
| resolution | String | false | Case-sensitive resolution supported by the selected model. |
| mode | String | false | `animate` or `replace`, where supported by the model. |
| prompt | String | false | Optional instructions, up to 5000 characters. |
| negative_prompt | String | false | Optional negative instructions. |
| character_orientation | String | false | `image` or `video`; model-specific duration limits apply. |
| keep_original_sound | Boolean | false | Keep source audio in the generated video. |
| duration | Number | false | Optional driving duration; must satisfy the selected model limits. |
| webhookUrl | String | false | Optional final-state callback URL; follow the [Webhook guide](/ai-tools-suite/webhook). |

**Response Attributes**

| **Parameter** | **Type** | **Description** |
|---|---|---|
| code | Integer | Business response code; `1000` means the request succeeded. |
| msg | String | Response message. |
| data | Object | Batch creation result. |
| - list | Array | Successfully created tasks. |
| -- _id | String | Task ID to use for result polling. |
| -- status | Integer | Initial task status. |
| -- media_type | String | Output media type: image or video. |
| -- model_name | String | Selected model ID. |
| -- deduction_credit | Number | Task billing amount. |
| -- create_time | Number | Creation timestamp in milliseconds. |
| - errors | Array | Inputs that could not create a task. Inspect this array even when code is 1000. |
| -- index | Integer | Zero-based plan/input index that failed during submission. |
| -- error | String | Submission failure description. |

**Example**

**Body**

```json
{
  "video": "https://example.com/motion.mp4",
  "images": [
    "https://example.com/character.jpg"
  ],
  "model_name": "kwaivgi/kling-v3.0-pro/motion-control",
  "resolution": "720P",
  "character_orientation": "video",

```

## Get task detail

```
GET https://openapi.akool.com/api/open/v5/motionSwap/task/detail?_id={{task_id}}
```

**Request Headers**

| **Parameter** | **Value** | **Description** |
|---|---|---|
| x-api-key | API Key | API key used for authorization. Authorization takes precedence when both headers are supplied. |
| Authorization | Bearer `{token}` | [Get Token](/authentication/usage#get-the-token). |
| Content-Type | application/json | Required for JSON requests. |

**Query Attributes**

| **Parameter** | **Type** | **Required** | **Description** |
|---|---|---|---|
| _id | String | true | A task ID from the creation response. Only tasks belonging to your user/team are accessible. |

**Response Attributes**

| **Parameter** | **Type** | **Description** |
|---|---|---|
| code | Integer | `1000` for a successful query. |
| msg | String | Response message. |
| data | Object | Task detail, including the task fields returned by creation. |
| - status | Integer | 1 = queueing, 2 = processing, 3 = completed, 4 = failed. |
| - url | String | Output URL, available after completion. |
| - progress | Number | Processing progress, when available. |
| - error_reason | String | Failure reason, when available. |
| - multi_shot_results | Array | Additional hairstyle views; empty for other operations. |

```bash cURL
curl --location 'https://openapi.akool.com/api/open/v5/motionSwap/task/detail?_id=670000000000000000000002' \
--header 'x-api-key: {{API Key}}'
```

The `url` field may be empty before completion. Use it only when `status` is 3. Poll until `status` is 3 or 4. A query with `code: 1000` may still describe a failed generation task; inspect `data.status` and `data.error_reason`.

## Billing

Generation is priced using the selected model configuration and your account/team pricing. Image generation is charged per task; video pricing also depends on duration and resolution. Credits are reserved before queueing and finalized through the existing generation billing flow. Creation errors do not produce a billable task. Read `deduction_credit` per created task rather than treating the sample value as a price quotation.

## Response Code Description

<Note>A business code other than 1000 indicates that the API request failed. For batch creation, also check data.errors.</Note>

| **Code** | **Description** |
|---|---|
| 1000 | Request succeeded. Inspect task status for generation results. |
| 1003 | Invalid input, unsupported model/parameters, unavailable feature, or task/analysis not found. |
| 1008 | Content does not exist (general platform error). |
| 1009 | Permission denied. |
| 1101 | Invalid or expired authorization. |
| 1102 | Authorization is missing. |
| 1104 | Insufficient credits. |

See the [Webhook guide](/ai-tools-suite/webhook) for callback verification and the [complete error list](/ai-tools-suite/error-code) for other account errors.

## Callback

If `webhookUrl` is supplied, final task notifications follow the existing encrypted and signed [Webhook format](/ai-tools-suite/webhook). After verification and decryption, read `_id`, `status`, `type`, and `url`. Fetch task detail to obtain operation-specific fields, including additional hairstyle views. Return HTTP 200 to acknowledge delivery.

## Video limits

The server measures the driving video duration. The `duration` field does not trim the video. Input duration must satisfy the selected model configuration; Kling with `character_orientation: "image"` supports at most 10 seconds.

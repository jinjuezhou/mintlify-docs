title: "Analyze Source Material"

openapi: "POST /api/open/v5/characterSwap/analyze"
---

```
POST https://openapi.akool.com/api/open/v5/characterSwap/analyze
```

Use the same authorization headers as task creation.

<Note>Akool video replacement needs a completed person analysis of the same video. Image replacement uses face bounding boxes directly, and Kling video uses its own preparation workflow; neither needs an analyze_id.</Note>

**Body Attributes**

| **Parameter** | **Type** | **Required** | **Description** |
|---|---|---|---|
| url | String | true | Public source material URL. Use the identical URL during task creation. |
| media_type | String | true | image or video. Use the same media type and URL when creating an analysis-driven task. |
| type | String | false | This endpoint always performs person analysis. Omit type or send person; other accepted type values do not change the effective category. |

**Response Attributes**

| **Parameter** | **Type** | **Description** |
|---|---|---|
| code | Integer | Business response code. |
| msg | String | Response message. |
| data | Object | Newly created analysis. |
| - _id | String | Analysis ID. |
| - task_id | String | Downstream algorithm/provider task ID; may be empty until submission. Use `_id`, not this value, for task-detail queries. It may change between workflow stages. |
| - status | Integer | Initially 1 (queueing). |
| - media_type | String | Source media type. |

Save `data._id` as the analysis ID.

<Note>For input limits, billing, callbacks, and error codes, see the [Character Swap V5 overview](/ai-tools-suite/swap-studio/character-swap-v5).</Note>

---
title: "Create Task"
description: "Create Task for Character Swap V5."
openapi: "POST /api/open/v5/characterSwap/create"
---

```
POST https://openapi.akool.com/api/open/v5/characterSwap/create
```

**Request Headers**

| **Parameter** | **Value** | **Description** |
|---|---|---|
| x-api-key | API Key | API key used for authorization. Authorization takes precedence when both headers are supplied. |
| Authorization | Bearer `{token}` | [Get Token](/authentication/usage#get-the-token). |
| Content-Type | application/json | Required for JSON requests. |

**Body Attributes**

| **Parameter** | **Type** | **Required** | **Description** |
|---|---|---|---|
| media_type | String | true | `image` or `video`. |
| target_url | String | true | Public source scene image or video URL. |
| model_name | String | false | Defaults to `akool-premium-multi-person`. Get supported IDs from the models endpoint. |
| mappings | Array | conditional | Image: 1–2 mappings with `source_url`, `source_bbox`, and `target_bbox`. Akool video: 1–5 mappings with `obj_id` and `img_url`. |
| - source_url | String | image | Reference character image URL. |
| - source_bbox | Array | image | Reference face bounding box `[x1,y1,x2,y2]` in original-image pixels. |
| - target_bbox | Array | image | Target face bounding box `[x1,y1,x2,y2]` in original-image pixels. The same target box cannot be mapped twice. |
| analyze_id | String | Akool video | Completed analysis ID for the same source video. |
| - obj_id | Integer | Akool video | Person ID from the analysis result. |
| - img_url | String | Akool video | Reference character image URL. |
| character_orientation | String | false | Kling video: `image` or `video`; defaults to `video`. |
| image | String | Kling video | Reference character URL for a single-person Kling replacement. |
| resolution | String | false | Video output resolution. Select a value supported by the chosen model. |
| keep_original_sound | Boolean | false | Keep source video audio. |
| prompt | String | false | Optional generation instructions. |
| webhookUrl | String | false | Optional final-state callback URL; follow the [Webhook guide](/ai-tools-suite/webhook). |

**Response Attributes**

| **Parameter** | **Type** | **Description** |
|---|---|---|
| code | Integer | Business response code; `1000` means the request succeeded. |
| msg | String | Response message. |
| data | Object | Batch creation result. |
| - list | Array | Successfully created tasks. |
| -- _id | String | Task ID to use for result polling. |
| -- status | Integer | Initial task status. |
| -- media_type | String | Output media type: image or video. |
| -- model_name | String | Selected model ID. |
| -- deduction_credit | Number | Task billing amount. |
| -- create_time | Number | Creation timestamp in milliseconds. |
| - errors | Array | Inputs that could not create a task. Inspect this array even when code is 1000. |
| -- index | Integer | Zero-based plan/input index that failed during submission. |
| -- error | String | Submission failure description. |

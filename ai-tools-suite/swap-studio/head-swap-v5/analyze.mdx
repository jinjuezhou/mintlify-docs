---
title: "Analyze Source Material"
description: "Analyze Source Material for Head Swap V5."
openapi: "POST /api/open/v5/headswap/analyze"
---

```
POST https://openapi.akool.com/api/open/v5/headswap/analyze
```

Use the same authorization headers as task creation.

**Body Attributes**

| **Parameter** | **Type** | **Required** | **Description** |
|---|---|---|---|
| url | String | true | Public source material URL. Use the identical URL during task creation. |
| media_type | String | true | Must be video. |
| type | String | false | This endpoint always performs head analysis. Omit type or send head; other accepted type values do not change the effective category. |

## Request examples

Select a source scenario to view matching request and queued response examples. URLs and IDs are illustrative; replace them with your accessible source material.

**Body**

```json
{
  "url": "https://example.com/source.mp4",
  "media_type": "video",
  "type": "head"
}
```


**Response Attributes**

| **Parameter** | **Type** | **Description** |
|---|---|---|
| code | Integer | Business response code. |
| msg | String | Response message. |
| data | Object | Newly created analysis. |
| - _id | String | Analysis ID. |
| - task_id | String | Downstream algorithm/provider task ID; may be empty until submission. Use `_id`, not this value, for task-detail queries. It may change between workflow stages. |
| - status | Integer | Initially 1 (queueing). |
| - media_type | String | Source media type. |

Save `data._id` as the analysis ID.

<Note>For input limits, billing, callbacks, and error codes, see the [Head Swap V5 overview](/ai-tools-suite/swap-studio/head-swap-v5).</Note>

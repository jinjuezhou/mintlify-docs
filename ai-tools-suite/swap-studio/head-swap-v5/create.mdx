---
title: "Create Task"
description: "Create Task for Head Swap V5."
openapi: "POST /api/open/v5/headswap/create"
---

```
POST https://openapi.akool.com/api/open/v5/headswap/create
```

**Request Headers**

| **Parameter** | **Value** | **Description** |
|---|---|---|
| x-api-key | API Key | API key used for authorization. Authorization takes precedence when both headers are supplied. |
| Authorization | Bearer `{token}` | [Get Token](/authentication/usage#get-the-token). |
| Content-Type | application/json | Required for JSON requests. |

<Note>
Analyze the source video with media_type=video and type=head, wait for status=3 and track_manifest_url, then pass that analysis _id as analyze_id. Use the identical target_url and distinct mappings[].obj_id values from analysis_result.media.
</Note>

**Body Attributes**

| **Parameter** | **Type** | **Required** | **Description** |
|---|---|---|---|
| media_type | String | true | Always `video`. |
| target_url | String | true | Public source video URL; must match the completed analysis. |
| analyze_id | String | true | Completed head analysis ID. |
| mappings | Array | true | 1–5 objects pairing detected people with reference images. |
| mappings[].obj_id | Integer | true | Person ID from the analysis result. |
| mappings[].img_url | String | true | Reference head image URL. |
| model_name | String | false | Defaults to `akool-premium`. |
| resolution | String | false | `480p` or `720p`; uses the selected model default, otherwise `480p`. |
| prompt | String | false | Optional generation instructions, up to 5000 characters. |
| keep_original_sound | Boolean | false | Keep source video audio; defaults to true. |
| webhookUrl | String | false | Optional final-state callback URL; follow the [Webhook guide](/ai-tools-suite/webhook). |

**Response Attributes**

| **Parameter** | **Type** | **Description** |
|---|---|---|
| code | Integer | Business response code; `1000` means the request succeeded. |
| msg | String | Response message. |
| data | Object | Batch creation result. |
| - list | Array | Successfully created tasks. |
| -- _id | String | Task ID to use for result polling. |
| -- task_id | String | Downstream algorithm/provider task ID; may be empty until submission. Use `_id`, not this value, for task-detail queries. It may change between workflow stages. |
| -- status | Integer | Initial task status. |
| -- media_type | String | Output media type: image or video. |
| -- model_name | String | Selected model ID. |
| -- deduction_credit | Number | Task billing amount. |
| -- create_time | Number | Creation timestamp in milliseconds. |
| - errors | Array | Inputs that could not create a task. Inspect this array even when code is 1000. |
| -- index | Integer | Zero-based plan/input index that failed during submission. |
| -- error | String | Submission failure description. |

## Overview

AKOOL provides a **Model Context Protocol (MCP)** server that exposes face swap, image generation, TTS, and more as native tools inside AI assistants — no manual API calls needed.

<Note>
  Using ChatGPT, Claude, Claude Code or Codex? Sign in with your AKOOL account
  instead of using API credentials. See [Plugin](/plugin).
</Note>

## Credentials

MCP uses the same credentials as the CLI. Get them from your [AKOOL dashboard](https://akool.com/workspace/current/api/credentials):

| Header            | Description                         |
| ----------------- | ----------------------------------- |
| `x-client-id`     | Your Client ID (`clientId`)         |
| `x-client-secret` | Your Client Secret (`clientSecret`) |

## Server Config

```json
{
  "mcpServers": {
    "akool-mcp": {
      "type": "http",
      "url": "https://openapi.akool.com/mcp/v1",
      "headers": {
        "x-client-id": "YOUR_CLIENT_ID",
        "x-client-secret": "YOUR_CLIENT_SECRET"
      }
    }
  }
}
```

## Setup Guides

<Note>
  **CLI quick-add** is only supported by **Claude Code**. All other clients
  (Cursor, Windsurf, Codex, Kiro) require editing a config file.
</Note>

### Claude Code

**Install**

```bash
npm install -g @anthropic-ai/claude-code
```

**Add AKOOL MCP**

```bash
claude mcp add --transport http akool-mcp https://openapi.akool.com/mcp/v1 \
  --header "x-client-id: YOUR_CLIENT_ID" \
  --header "x-client-secret: YOUR_CLIENT_SECRET"
```

Verify:

```bash
claude mcp list
# akool-mcp   http   https://openapi.akool.com/mcp/v1
```

### Claude Desktop

**Install**

Download and install from [claude.ai/download](https://claude.ai/download).

**Add AKOOL MCP**

1. Go to **Customize** → **Connectors** → **+ Add** → **Add custom connector**.
2. Name it `akool-mcp` and enter `https://openapi.akool.com/mcp/v1` as the URL.
3. Under **Request headers**, add `x-client-id` and `x-client-secret` with your credentials.
4. Choose **No sign in**, then add the connector.

### Cursor

**Install**

Download from [cursor.com](https://www.cursor.com/), install and open.

**Add AKOOL MCP**

Go to **Settings** → **MCP** → **Add new global MCP server**, or edit `~/.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "akool-mcp": {
      "type": "http",
      "url": "https://openapi.akool.com/mcp/v1",
      "headers": {
        "x-client-id": "YOUR_CLIENT_ID",
        "x-client-secret": "YOUR_CLIENT_SECRET"
      }
    }
  }
}
```

Restart Cursor. In the **Agent** panel, AKOOL tools will appear under **Available Tools**.

### OpenAI Codex

**Install**

```bash
npm install -g @openai/codex
```

**Add AKOOL MCP**

Edit `~/.codex/config.toml`:

```toml
[mcp_servers.akool-mcp]
url = "https://openapi.akool.com/mcp/v1"
http_headers = { "x-client-id" = "YOUR_CLIENT_ID", "x-client-secret" = "YOUR_CLIENT_SECRET" }
```

Codex will automatically load MCP servers on startup.

## Usage Examples

Once configured, describe tasks in natural language:

**Face swap (image)**

```
Swap the face in source.jpg onto target.jpg using AKOOL, save the result URL
```

**Face swap (video)**

```
Use AKOOL to swap the face from face.jpg onto video.mp4, then wait for the result
```

**Enhanced face swap**

```
Use AKOOL faceswap_plus to swap multiple faces in group.jpg with the source face
```

**Generate image**

```
Ask AKOOL to generate an image: cinematic portrait of an astronaut on Mars, golden hour
```

**Image to video**

```
Use AKOOL to turn hero.jpg into a video clip with the "zoom" effect
```

**Text to speech**

```
List available AKOOL voices, then convert this script to speech using a female English voice:
"Welcome to our annual product showcase."
```

**Face detection**

```
Use AKOOL to detect all faces in photo.jpg and return their bounding boxes
```

**Check account**

```
Check my AKOOL credit balance and list available AI models
```

## Tips

- Never commit `x-client-id` / `x-client-secret` to source control. Store them in environment variables and reference via your MCP client's env substitution (e.g. `$AKOOL_CLIENT_ID`).
- Run `akool-cli credit` first to confirm your credentials are valid before configuring any MCP client.
- Most AKOOL tools are **async** — the assistant will call `*_result` tools automatically to poll until the job completes.
- If a tool call returns `401 Unauthorized`, verify credentials at the [AKOOL dashboard](https://akool.com/workspace/current/api/credentials).

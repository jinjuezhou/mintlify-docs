## Overview

AKOOL provides a **Model Context Protocol (MCP)** server that exposes face swap, image generation, TTS, and more as native tools inside AI assistants — no manual API calls needed.

## Credentials

MCP uses the same credentials as the CLI. Get them from your [AKOOL dashboard](https://akool.com/workspace/current/api/credentials):

| Header            | Description                         |
| ----------------- | ----------------------------------- |
| `x-client-id`     | Your Client ID (`clientId`)         |
| `x-client-secret` | Your Client Secret (`clientSecret`) |

## Server Config

```json
{
  "mcpServers": {
    "akool-mcp": {
      "type": "http",
      "url": "https://openapi.akool.com/mcp/v1",
      "headers": {
        "x-client-id": "YOUR_CLIENT_ID",
        "x-client-secret": "YOUR_CLIENT_SECRET"
      }
    }
  }
}
```

## Available Tools

| Tool                    | Description                                             |
| ----------------------- | ------------------------------------------------------- |
| `faceswap_image`        | Swap a face from a source image onto a target image     |
| `faceswap_video`        | Swap a face from a source image onto a target video     |
| `faceswap_result`       | Poll the result of an async faceswap job                |
| `character_swap_create` | Submit a character swap task                            |
| `character_swap_result` | Poll the result of a character swap job                 |
| `image_generate`        | Generate an image from a text prompt or reference image |
| `image_result`          | Poll the result of an async image generation job        |
| `image_upscale`         | Upscale an image to higher resolution                   |
| `image_to_video`        | Convert a static image into a short video clip          |
| `voice_list`            | List all available TTS voices                           |
| `voice_tts`             | Convert text to speech with a chosen voice              |
| `voice_result`          | Poll the result of an async TTS job                     |
| `credit_balance`        | Get your current AKOOL account credit balance           |

## Setup Guides

### Claude Code

**Install**

```bash
npm install -g @anthropic-ai/claude-code
```

**Add AKOOL MCP**

```bash
claude mcp add akool-mcp \
  --transport http \
  --url https://openapi.akool.com/mcp/v1 \
  --header "x-client-id: YOUR_CLIENT_ID" \
  --header "x-client-secret: YOUR_CLIENT_SECRET"
```

Or edit `~/.claude/mcp_servers.json` directly:

```json
{
  "mcpServers": {
    "akool-mcp": {
      "type": "http",
      "url": "https://openapi.akool.com/mcp/v1",
      "headers": {
        "x-client-id": "YOUR_CLIENT_ID",
        "x-client-secret": "YOUR_CLIENT_SECRET"
      }
    }
  }
}
```

Verify:

```bash
claude mcp list
# akool-mcp   http   https://openapi.akool.com/mcp/v1
```

### Claude Desktop

**Install**

Download and install from [claude.ai/download](https://claude.ai/download).

**Add AKOOL MCP**

Open Claude Desktop → **Settings** → **Developer** → **Edit Config**, then add:

- macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows: `%APPDATA%\Claude\claude_desktop_config.json`

```json
{
  "mcpServers": {
    "akool-mcp": {
      "type": "http",
      "url": "https://openapi.akool.com/mcp/v1",
      "headers": {
        "x-client-id": "YOUR_CLIENT_ID",
        "x-client-secret": "YOUR_CLIENT_SECRET"
      }
    }
  }
}
```

Restart Claude Desktop. A **hammer icon** (🔨) will appear in the chat input when MCP tools are ready.

## Usage Examples

Once configured, describe tasks in natural language:

**Face swap**

```
Swap the face in source.jpg onto target.jpg using AKOOL, save the result URL
```

**Character swap**

```
Use AKOOL to do a character swap: source image is source.png, target is target.png
```

**Generate image**

```
Ask AKOOL to generate an image: cinematic portrait of an astronaut on Mars, golden hour
```

**Image to video**

```
Use AKOOL to turn hero.jpg into a 5-second animated video clip
```

**Text to speech**

```
List available AKOOL voices, then convert this script to speech using a female English voice:
"Welcome to our annual product showcase."
```

**Check credits**

```
Check my AKOOL credit balance
```

## Tips

- Never commit `x-client-id` / `x-client-secret` to source control. Store them in environment variables and reference via your MCP client's env substitution (e.g. `$AKOOL_CLIENT_ID`).
- Run `akool-cli credit` first to confirm your credentials are valid before configuring any MCP client.
- Most AKOOL tools are **async** — the assistant will call `*_result` tools automatically to poll until the job completes.
- If a tool call returns `401 Unauthorized`, verify credentials at the [AKOOL dashboard](https://akool.com/workspace/current/api/credentials).
